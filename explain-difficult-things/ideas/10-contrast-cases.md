# Contrast near-misses

Put an example next to a near-miss that differs in only one thing.

## Why

A feature is noticed only when it varies against a background that stays the same. If an example and a non-example differ in five ways, the reader cannot tell which difference mattered. Comparing cases that differ in one way first also prepares the reader for the explanation that follows.

## How

- Keep everything the same except the feature you want seen. Same names, same layout, same wording.
- Say that they differ, and where.
- Then show two examples that look very different but are both cases of the idea, to show its range.
- When the separate features are clear, show a case where several vary together.
- To check, mix new examples and non-examples in an order that has no pattern.

## Example

Two versions of the same "reserve stock" function, side by side. One reads the count and then writes it. The other does both in one atomic update. Everything else is identical. Under two concurrent buyers, the first oversells and the second does not.

## Watch out

- A non-example that also changes names and layout teaches nothing.
- The cases do not replace the explanation. Compare first, then explain what the comparison showed.

Based on: variation theory (Marton); Engelmann and Carnine's examples and non-examples; contrasting cases (Schwartz and Bransford).
